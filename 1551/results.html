Results and files

#1What is here

Everything below is produced by one command and by nothing else. The five contract files are written by the pipeline stages; the report and the Excel workbook are rebuilt from those five files afterwards, so neither can contain a value the contract does not. Every number on this site is read from the same files at build time. Sizes and counts on the cards are read from the files themselves.

#2Report

hesabat.pdf
— the 4-page report: headline paths with bands, nominal levels with their price basis, the comparison overlay and the reference values, and the method summary. 749 kB · hesabat.pdf
hesabat.html
— the same report as a single HTML file with the mathematics rendered inline. 348 kB · hesabat.html

#3Results workbook

  • neticeler_15_5_1.xlsx — 18 sheets: contents, the statutory sheet layout, one sheet per requirement, the assumption set and Geriyə Sınaq (the backtest ledger). Built only from the five contract files, with no hand-placed value and no external links. 133 kB · neticeler_15_5_1.xlsx

#4The output contract

forecast_long.csv
— every published series in long form: 13,994 rows across 613 series, with the source column separating our path, the template-sample overlay, the Ministry specification scenario and the IMF reference values. 1.6 MB · forecast_long.csv
equations_catalog.csv
— 478 estimated equations with their left- and right-hand sides, sample years, adjusted R² and regression standard error. 173 kB · equations_catalog.csv
validation_backtest.csv
— the backtest ledger: 6,709 rows across 168 series and 111 model labels, including the candidates that lost. 978 kB · validation_backtest.csv
series_dictionary.csv
— 641 series with Azerbaijani and English names, unit, requirement, statutory sheet reference and price basis. 163 kB · series_dictionary.csv
assumptions.csv
— every forecast-horizon input: 63 keys × five years = 315 rows, with unit and note. 88 kB · assumptions.csv
SXEM.md
— the column-by-column schema of the five files above, supplied with the delivery package.
