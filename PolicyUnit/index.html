Ssenarilər, təsirlər, KPI, hesabat

Hər ssenarinin əsas nəticələri bir baxışda, sonra ətraflı təhlil — bir neçə kliklə.

  • Ssenari qurucusu: alətlər kataloqundan seçin, ölçü, illər, hədəf sektor, maliyyələşmə
  • Makro və mikro təsirlər (qısa / orta / uzun), IO sektor təsirləri, sosial təsirlər
  • Yan təsirlər və risk profili, KPI ilə çoxkriteriyalı reytinq, metodların müqayisəsi
  • Tarixi validasiya (sapma hesabatı); hesabat qurucusu (PDF, Excel, Word, CSV)

MİİS-in digər modulları

Siyasət təsiri bu modulların baza proqnozları və risk paylanmaları üzərində qurulur.

  • MikroUnit İş paneli (§15.5.2) — Sektor, bazar müvazinəti, rəqabət, məşğulluq — siyasət təsirlərinin əsas mühərriki
  • Risk paneli (§15.5.3) — Risk reyestri, paylanmalar, stress testləri — siyasətin risk profili buradan gəlir
  • Makro proqnozlar (§15.5.1) — OxLon və Nazirlik makro modelləri — baza proqnozu

Sənədlər və API

Metodologiya

  • Yan təsirlər və risk inteqrasiyası — FR4 · paneldə oxu
  • Girdi-çıxdı (IO) modeli — FR2 · paneldə oxu
  • Nüvə: FR1 makro/mikro, FR5 KPI, NFR2, NFR4 · paneldə oxu
  • Mikrosimulyasiya — FR3 (SİNTETİK məlumat) · paneldə oxu
  • Sapma hesabatı — tarixi validasiya (NFR1) · paneldə oxu
  • Konfiqurasiya: yeni ssenari və alət (NFR4)

API

  • API təsviri (OpenAPI) api/openapi.yaml

Yeni ssenarinin hesablanması üçün

SiyasetModel_Baslat.command (macOS) və ya SiyasetModel_Baslat.bat (Windows) faylını iki dəfə klikləyin — yerli server başlayır və panel brauzerdə açılır. Server olmadan panel tam işləyir (bütün nəticələr paketdədir); yalnız yeni hesablama aparıla bilmir.
